# Changelog

Все значимые изменения проекта документируются в этом файле.

## [0.1.0] - 2026-11-04

### Added

- Нормализация URL по общим правилам.
- Определение источника ссылки: YouTube, Reddit и Generic.
- Нормализация ссылок YouTube.
- Нормализация ссылок Reddit.
- Извлечение ID видео YouTube и постов Reddit.
- Исключение `InvalidURLError` для некорректных URL.
- Тесты для правил нормализации и определения источника.
- Проверка идемпотентности нормализации.
- CI на GitHub Actions с Ruff, Mypy и Pytest.
